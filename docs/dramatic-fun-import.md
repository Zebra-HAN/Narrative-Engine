# 극적 재미 DB 적용

스토리의 첫 번째 카테고리 `dramatic_fun`에 등록했다. 카테고리 이미지는 실제 사건 NAV의 `images/core/sub-nav/stry/event.webp`를 참조한다. 기존 스토리 NAV와 카드 데이터는 보존한다.

| 그룹 | 섹션 | 카드 | 공식 |
| --- | ---: | ---: | ---: |
| 인물 · 설정 · 조건 | 6 | 61 | 258 |
| 갈등 · 행동 · 해결 | 6 | 74 | 340 |
| 사건 · 구조 · 전개 | 6 | 58 | 238 |
| 발견 · 변화 · 감정 | 6 | 63 | 248 |
| 합계 | 24 | 256 | 1,084 |

그룹명은 사용자가 지정한 명칭을 적용한다. 원본의 그룹·섹션·카드·공식 순서는 유지한다. 화면 제목의 관리용 번호와 섹션에 붙은 분류 설명만 제거한다. HTML 문자 참조와 Markdown 번호 이스케이프는 표시 문자열로 해석한다. 원문은 `dramatic-fun-source.md`에 그대로 보관한다.

카드 `name`은 원문의 세부 주제다. `desc`는 해당 주제를 안내하는 새 간략 설명이며 원본 공식과 구분한다. `detail`에는 `【공식 제목】\n설명\n예시`를 저장하고 공식 사이는 `\n\n`으로 구분한다. 기존 단일 열 파서는 공식별로 한 섹션과 한 선택 블록을 생성하므로 설명과 예시가 함께 선택된다. 새 필드나 상세정보 UI는 추가하지 않는다. 카드·섹션은 객체당 한 줄로 저장한다.

그룹·섹션·카드에 이미지와 아이콘을 지정하지 않는다. 새 카테고리에만 적용되는 CSS로 빈 카드 이미지 프레임, 상세정보의 기본 아이콘, 그룹 제목 카드의 기본 도형을 숨긴다. 기존 장식·테두리와 다른 카테고리는 유지한다.

검증: `node --check data/narrative.js`, `node --check sw.js`, `node tests/dramatic-fun.cjs`. 브라우저 검증은 기본 `http://127.0.0.1:8003`이며 `PERF_TEST_URL`로 변경할 수 있다. 별도 빌드 도구가 없는 정적 웹앱이다.
